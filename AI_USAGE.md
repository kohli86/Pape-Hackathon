# AI-use disclosure — draft for team review

Generative AI assistance was used to help draft and revise the project structure, interface copy, HTML/CSS styling, JavaScript prototype logic, procedural level-generation approach, and documentation for AquaGrid.

The Vector Coders team should review and understand the code, make its own design and implementation decisions, test the finished game, and record any additional AI tools or assistance actually used. Before submission, edit this file so it accurately reflects the team's real contributions and complies with the hackathon's AI-use disclosure requirements.

Additional assistance: AI was used to help revise the game rules and create the school illustration asset and countdown-state styling. The team should review, understand, test, and further customize these changes before submission.


Three schoolyard illustrations (`school-stable.webp`, `school-strained.webp`, and `school-critical.webp`) were generated specifically for AquaGrid and exported as separate image assets. They depict the same fictional community school under stable, strained, and critical water-supply conditions. A user-supplied picture was used only as broad reference for a warm, simplified flat-vector character-illustration aesthetic; its characters, pose, and composition were not reproduced. JavaScript switches between the three images as the level timer falls.
